# CodeAlpha Social Media Platform

A simple social media web application developed using Django for the CodeAlpha Full Stack Development Internship.

## Project Overview

This project demonstrates the core features of a social media platform, including user authentication, profiles, posts, comments, likes, follows, and database management.

## Features

- User Registration
- User Login and Logout
- User Profiles
- Edit Profile
- Create Posts
- Edit and Delete Own Posts
- Comments
- Like and Unlike Posts
- Follow and Unfollow Users
- Followers and Following
- Home Feed
- Responsive Design
- Django Admin

## Technologies Used

- Python
- Django
- HTML5
- CSS3
- SQLite
- Git
- GitHub
